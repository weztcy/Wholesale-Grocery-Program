# Wholesale Grocery Program

**Wholesale Grocery Program** is a Java-based application designed to record and manage wholesale grocery transaction data in a structured and organized format.

The program handles essential transaction information such as invoice numbers, product codes, product names, purchase prices, selling prices, and payment methods.

## 🛒 About the Project

Wholesale Grocery Program was developed to support the recording of basic wholesale grocery transactions.

The application provides a structured workflow for entering product and transaction information, helping maintain consistent records for each transaction.

Users can record invoice details, identify products using product codes, manage pricing information, and specify the payment method used for each transaction.

## ✨ Features

Key features and implementations include:

* Invoice number recording
* Product code input
* Product name recording
* Purchase price management
* Selling price management
* Payment method selection
* Cash payment support
* Credit payment support
* Structured transaction data entry
* Organized transaction information display

## 💳 Payment Types

The program supports two payment methods:

* **Cash** — payment completed directly at the time of transaction
* **Credit** — payment recorded with deferred payment terms

## 🛠️ Technology

The main technology used in this project is:

* Java

## 🎯 Project Objectives

This project was developed to:

* Provide a structured system for recording wholesale grocery transactions
* Organize product and pricing information within each transaction
* Maintain consistent invoice and product data records
* Support both cash and credit payment methods
* Simplify transaction data entry and information management
* Provide a functional foundation for further wholesale transaction management features

## 📋 Data Managed

The program manages the following transaction information:

* Invoice Number
* Product Code
* Product Name
* Purchase Price
* Selling Price
* Payment Type
